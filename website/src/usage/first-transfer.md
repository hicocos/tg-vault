# 第一次转存

从 Web 上传开始，确认目标和文件内容后，再配置 Bot 或远端存储。

## A. 先验证 Web 与本地

1. 登录管理页，在 **设置 → 存储** 确认本地存储可写、路径正确且空间充足。
2. 在 **上传中心** 选择存储和文件夹，上传一个无敏感内容的测试文件。
3. 等待任务完成，在文件管理中下载并核对内容。
4. 如需检查磁盘位置，到宿主机的 `/data` 挂载目录查看；它不是浏览器所在电脑的目录。

上传失败时，先按[排错指南](/troubleshooting/)检查错误、权限和磁盘空间。

## B. 给自己的 Bot 发一个文件

先完成 [Telegram 配置](/deploy/telegram)，准备 Token、API ID/Hash、PIN 和允许用户。

1. 私聊 Bot，发送 `/start` 完成认证；开启 TOTP 时按提示二次验证。
2. 用 `/target` 检查保存账户，用 `/path_rules` 检查目录。
3. 直接发送测试文件，用 `/tasks` 或 Web **任务** 查看结果。
4. 在文件管理中下载文件并核对内容。

启用个人账号后，带完整原帖来源的转发可能由账号读取原帖，需要该账号有来源权限，详见[来源规则](/deploy/telegram#_4-转发文件的来源规则)。

## C. 接入一个远端目标

1. 按[存储指南](/storage/)添加账户。
2. 核对默认账户：OneDrive/Google Drive 授权成功会成为默认，其他类型不会自动切换。
3. 单独检查 Bot `/target` 和订阅固定目标。已创建任务的目标不会随默认切换。
4. 上传后在提供方网页或官方客户端确认文件，再下载检查。经网关接入时，还需确认背后云盘的最终状态。

## D. 再扩大使用范围

需要保存历史或持续同步频道内容时，在[频道下载与订阅](/usage/subscriptions)中设置来源、范围和过滤规则。任务的扫描、下载、上传与处理阶段见[任务管理](/usage/tasks)。
