# qBittorrent 扩展

此扩展通过本机 qBittorrent 下载后转存，默认关闭。需在 TG Vault 所在服务器自行运行下载器，配置 WebUI 端口、账号密码和本地下载目录。

## 1. 确认本机服务与下载目录

TG Vault 与 qBittorrent 在同一服务器直接运行，使用相同的绝对下载目录，默认 `/qBittorrent/download`。目录须预先创建，允许下载器写入、TG Vault 后端读取。

后端固定通过本机 `127.0.0.1` 连接 qBittorrent，仅支持填写 WebUI 端口，不支持远程下载器。不提供远程路径转换。

## 2. 启用与测试

1. 在 **设置 → 常规** 启用扩展，打开 **BT 下载**。
2. 填写 **WebUI 端口**（1–65535，默认 8080）、专用账号/密码和本地下载目录。例如原地址为 `http://127.0.0.1:18080`，仅填写 `18080`。
3. 点击 **测试连接和目录**。测试仅检查填写值，不保存配置或修改下载器全局设置。
4. 保存生效。密码留空保留原值，凭据加密保存且不回显。

qBittorrent 的 WebUI 须允许通过 `http://127.0.0.1:<端口>` 访问。保留其鉴权、Host 和 CSRF 校验。

升级后旧的完整 API 地址不再用于连接，需重新填写并保存本机端口。已有任务仍校验原连接，连接不一致时停止处理。

## 3. 添加与转存

添加磁力链接或最大 **10 MiB** 的 `.torrent` 文件。磁力需等待元数据，再选择文件、目标账户和逻辑目录，并决定是否保留本地文件做种。

- 转存开始后不能改选文件；切换默认存储不改变任务目标。
- 保留目录结构，下载和转存分别显示进度与速度。
- 所选文件全部写入并入库后，默认删除下载器种子和源文件；选择保留则继续做种。
- 存储确认并入库后转存才到 100%。

**取消会删除下载器任务及源文件，包括未完成文件，不受“保留本地文件”影响。已转存文件不删除。** 需要保留做种时不要使用取消。

## 4. 失败、历史与关闭

失败可重试，已入库文件不重复上传；清理或删除失败时仅重试对应操作，不重新下载或转存。重启后恢复未结束任务；已有种子不能重复添加，也不接管下载器其他任务。

完成和取消任务进入历史。移除记录不删除存储文件、本地文件或做种任务。关闭扩展只停止转存调度，不删除记录或停止下载器现有下载；下载器离线不影响 TG Vault 启动。

## 容量与备份

本地转存和媒体处理使用独立副本，需预留额外空间。外部 BT 下载目录和下载器配置不包含在 TG Vault `/data` 备份中，需另行备份。
