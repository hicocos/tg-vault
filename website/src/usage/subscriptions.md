# 频道下载与订阅

需要已启用且有来源访问权限的 **Telegram 个人账号**。先用该账号打开原帖；Bot 认证不能替代频道访问权限。私有来源通常需先加入，TG Vault 不自动加入私有来源或绕过内容保护。多个账号的添加、启用、冷却与分配规则见[多账号调度](/usage/multi-account)。

## 先分清历史任务与新内容同步

| 需求 | 入口 | 行为 |
| --- | --- | --- |
| 下载历史文件 | Bot `/tg_download` | 按日期或标签选择范围 |
| 持续同步新内容 | Web **订阅中心 → 新增订阅** 或 Bot `/tg_sub` | 从创建时最新消息之后开始，不回填历史 |
| 管理订阅 | Web 订阅中心、Bot `/tg_sub` / `/tg_subs` | 查看、修改、暂停或恢复 |

## 小范围下载历史

1. 发送 `/tg_download`，选择日期或标签方式。
2. 按向导输入来源与范围，日期格式、标签和时区以向导说明为准。
3. 核对保存账户、相对目录、文件类型和评论区选项，确认后提交。
4. 在 Web 或 Bot 查看扫描、下载、失败和跳过明细。

扫描时总量可能未知；批量 100% 表示已发现条目处理完，不代表全部成功。

## 在 Web 创建订阅

1. 启用 Bot，并至少让一个允许用户完成 `/start` 认证。
2. 打开 **订阅中心 → 新增订阅**，填写频道用户名或链接。
3. 选择已认证的数字通知用户。列表为空时，先到 Telegram 完成认证。
4. 选择 **跟随全局** 或固定本地/指定存储账户，填写相对目录，配置广告过滤和文件类型。
5. 创建后查看后续新媒体的扫描、任务和保存结果。

这里的“账户”是**目标存储账户**，不是 Telegram 下载账号。跟随全局使用未来扫描时的默认存储账户；固定目标不受默认切换影响。**已创建任务保持原目标。** 同一用户重复添加会恢复原订阅并保留游标，不会重新回填历史。

## 文件类型与广告过滤

文件类型可选不限制、只保存所选类型或忽略所选类型；广告过滤可选关闭、保守或激进。

- 排除的文件不会下载，订阅仍继续扫描后续消息。
- 显式类型选择优先于全局“跳过普通图片”，不限制模式沿用全局设置。
- 普通照片消息与作为文件发送的图片不同，“跳过普通图片”不会跳过所有图片文件。
- 修改规则仅影响后续扫描，不处理或删除已保存文件。

## 暂停、恢复和游标

暂停只停止后续同步调度，不取消已创建任务或删除文件。恢复仍受来源权限和 FloodWait 限制。

修改目标或目录不会移动旧文件。历史内容用 `/tg_download` 处理，不要通过修改数据库游标或重复添加来源重置进度。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| 无法访问私有来源 | 个人账号是否加入、能否读取原帖与历史 |
| 新建后没有旧内容 | 新订阅不回填，历史下载用 `/tg_download` |
| 有扫描但没文件 | 消息是否有媒体、类型规则、普通图片设置、广告过滤 |
| 任务等待或速度归零 | Telegram 冷却、磁盘空间、目标存储、任务占用 |
| 改目标后旧任务仍去旧账户 | 核对任务创建时间，目标在创建时固定 |
