# Web 上传与文件管理

## 上传前先看目标

1. 打开 **上传中心**，等待上传能力加载，确认存储账户和目标文件夹。
2. 选择或拖入文件。分片方式、请求大小等以服务端返回的能力为准。
3. 在队列查看进度；传输结束后仍可能需要处理和保存。
4. 完成后在文件管理中打开或下载结果。

任务创建后固定目标，切换默认账户不影响在途任务。大文件分片需要暂存和合并空间；单次请求、会话总大小、分片数和磁盘预算均有限制，见[资源说明](/deploy/resources)。

## 中断与恢复

在上传队列继续可恢复的上传，按提示重新选择本地源文件。浏览器关闭后，服务端无法继续读取电脑上的文件。

任务中心的 Web 上传“继续”会返回上传队列。先检查错误和会话有效期，避免重复新增同一批文件。

## 搜索、分类与目录

文件管理支持搜索、类型筛选、收藏、文件夹整理、重命名和媒体预览。预览取决于格式、处理结果和浏览器支持。

页面只显示 TG Vault 已建立索引的内容，添加账户不会导入远端整盘。不要手工把未索引文件放入受管理的 uploads 目录，孤儿文件清理可能删除它们。

## 新文件命名与重复策略

| 规则 | 行为 |
| --- | --- |
| 新文件 | 清理非法字符、限制长度后优先保留原名，不追加 UUID |
| `copy` | 同账户、同目录重名时添加 `（1）`、`（2）` 等编号，放在扩展名前 |
| `skip` | 跳过同账户、同目录、同名且同大小的文件，不按内容哈希全局去重 |
| 已有文件 | 不自动改名；展示名保留来源名称 |

避免外部工具并发写入受管理目录，以免重名冲突或索引不一致。

## 删除、移除记录与移除账户

| 操作 | 影响 |
| --- | --- |
| 删除文件 | 涉及实际文件与索引，执行前核对确认页和批量选择范围 |
| 清理已结束任务记录 | 不删除、恢复或撤销已保存文件 |
| 移除存储账户 | 删除连接与关联记录，不删除远端文件；默认账户或有任务占用时不能直接移除 |

不要手工删除数据库行或本地目录来代替应用内删除。
