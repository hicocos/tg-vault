# Bot 命令速查

先在 Web 配置允许用户与 PIN，再私聊 Bot 发送 `/start` 完成认证。菜单只展示常用命令，完整帮助使用 `/help`。删除、取消等操作执行前需核对预览和确认页。

## 常用与文件

| 命令 | 用途 |
| --- | --- |
| `/start` | 开始使用、验证身份 |
| `/help` | 完整帮助 |
| `/tasks` | 实时传输任务队列 |
| `/storage` | 存储状态；可确认删除本地实体文件，谨慎操作 |
| `/path_rules` | 保存位置与自定义目录面板 |
| `/target` | 设置下一次或当前聊天持续使用的存储账户，不修改系统默认 |
| `/storage_switch` | 切换系统默认存储，影响新的默认保存操作 |
| `/p <目录>` | 设置下一次保存目录 |
| `/ps <目录>` | 设置当前会话持续使用的目录 |
| `/pc` | 清除下一次和当前会话的自定义目录 |
| `/delete <文件ID前缀>` | 按至少 8 位文件 ID 前缀删除文件 |

## 频道与订阅

| 命令 | 用途 |
| --- | --- |
| `/tg_download` | 打开按日期或标签下载向导 |
| `/tg_sub` | 频道自动同步管理向导 |
| `/tg_subs` | 查看订阅列表 |
| `/tg_unsub <频道或订阅ID>` | 请求取消对应订阅 |
| `/tg_retry [数量] [任务ID]` | 重试最近失败的 Telegram 下载任务 |

频道下载与订阅需要有来源访问权限的个人账号，见[频道下载与订阅](/usage/subscriptions)。

## 任务与系统

| 命令 | 用途 |
| --- | --- |
| `/task_pause [任务ID]` | 暂停当前聊天或指定任务 |
| `/task_resume [任务ID]` | 继续适用任务，不绕过服务端冷却 |
| `/task_cancel <任务ID或all>` | 预览并取消任务 |
| `/stop_tasks` | 预览并停止当前聊天下载任务 |
| `/download_workers` | 单文件分片并发，4/6/8/10/12，10/12 需再次确认 |
| `/file_concurrency` | 同时下载文件数，1–10 且受已启用账号数约束 |
| `/duplicate_mode` | 同目录同名同大小的重复处理策略 |
| `/cleanup_settings` | 自动清理未索引临时文件的开关 |
| `/status` | Bot、账号下载器、存储、磁盘、队列、订阅和对账诊断 |
| `/notifications` | 成功/失败/订阅摘要、时区与安静时段；安全告警即时 |

并发设置见[资源指南](/deploy/resources)。自动清理不用于迁移或导入文件。

## 安全与语言

| 命令 | 用途 |
| --- | --- |
| `/setup_2fa` | 配置 TOTP 双重验证 |
| `/logout` | 立即撤销当前 Telegram 用户的 Bot 认证，不等同于撤销个人账号 session |
| `/language` | 选择简体中文、English、Русский |
