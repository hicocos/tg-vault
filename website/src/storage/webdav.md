# WebDAV 与 NAS

先在服务商或 NAS 开启 WebDAV，获取 **DAV endpoint** 并确认目标目录可写。不要填写网盘网页、分享链接或管理后台地址。

## 获取并填写参数

在 **设置 → 存储 → 添加存储 → WebDAV** 填写：

| 字段 | 内容 |
| --- | --- |
| 服务地址 | 完整 DAV 地址，子目录放在 URL 路径中 |
| 存储名称 | 可选显示备注 |
| 用户名 | 服务商要求的登录名，如邮箱或专用 DAV 用户 |
| 密码 | 应用口令或 DAV 密码 |

需要应用口令的服务不能直接填登录密码。用户名和密码选填仅适用于匿名服务；TG Vault 自动协商 Basic/Digest 认证。

点击 **验证并添加**，按需设为默认。连接测试不能代替实际读写权限检查。

## 局域网 NAS 的安全开关

默认拒绝 HTTP、回环、私有网段和保留地址。连接可信局域网 DAV 时，在 **设置 → 安全 → 网络与存储安全** 确认并开启 **允许内网和不安全的 WebDAV 地址**。

该开关扩大服务器可访问范围，并允许明文传输，存在 SSRF 和凭据泄露风险。**仅对 WebDAV 生效，不放宽 S3/OpenList，也不忽略 TLS 证书错误。**

- 地址须从 backend 容器可达；容器内 `127.0.0.1` 指容器自身。
- 检查 NAS 监听地址、路由、防火墙和 DAV 端口。
- HTTPS 仍需有效、受信任的证书链。
- 经异步网关转存时，需在背后云盘确认最终文件。

## 连接与大文件排错

| 现象 | 检查 |
| --- | --- |
| 401 | 用户名、应用口令、服务端认证要求 |
| 403 / 只读 | 用户的目标目录读写权限 |
| 404 | DAV endpoint、子路径和目录是否存在 |
| 地址被拒 | 是否需要启用可信内网接入 |
| TLS 失败 | 域名、证书链、系统时钟 |
| 长时间无响应 | 远端配额、代理、权限与网络 |

默认 `WEBDAV_INACTIVITY_TIMEOUT_MS=300000`（无活动 5 分钟）、`WEBDAV_UPLOAD_TIMEOUT_MS=21600000`（上传总计 6 小时）。调整超时不能修复权限、配额或网络问题。

使用 OpenList 的 DAV 接口时选 WebDAV 类型；[OpenList 原生接入](/storage/openlist)的服务地址不带 `/dav`。
