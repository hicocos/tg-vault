# 阿里云 OSS

OSS 是对象存储，不是阿里云盘，需注意容量、请求和外网流量费用。桶可保持私有。

## 准备桶与权限

1. 在 [OSS 控制台](https://oss.console.aliyun.com/) 创建或选择 Bucket，记录桶名与地域。
2. 创建专用 RAM 用户和 AccessKey，授权目标桶的列举、读取、写入及所需删除权限，不使用主账号 AccessKey。
3. 连接探测需要列举对象，仅写权限可能导致探测失败。

## 填写 TG Vault

打开 **设置 → 存储 → 添加存储 → Aliyun OSS**：

| 字段 | 内容 |
| --- | --- |
| 存储名称 | 显示备注 |
| Region | 从桶概览复制地域标识，如 `oss-cn-hangzhou` |
| Bucket | 桶名，不带协议、地域后缀或路径 |
| AccessKey ID / Secret | 同一 RAM 用户的密钥，不是阿里云登录密码 |

当前没有独立 Endpoint、自定义 CDN 或 STS SecurityToken 字段，不支持三段式临时凭据。

## 验收

点击 **验证并添加**，成功后不会自动切换默认。按需设为默认，上传后在 OSS 控制台确认对象并下载检查。

OSS 桶启用或暂停版本控制时可能忽略禁止覆盖头，重名策略不能保证外部并发写入的原子性。避免其他工具同时写入受管理目录，详见[文件命名说明](/reference/configuration#数据目录与上传限制)。

`AccessDenied` 先检查桶名、RAM 策略与列举/对象操作权限，不必开放全账号或公共读写权限。密钥泄露后应在阿里云撤销并更新接入配置，不要公开原始密钥。
